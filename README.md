# AURON COLLECT

AURON COLLECT is a receivables and collections platform for managing customers,
invoices, receipts, reminders, and subscription billing.

**Notification Channel: Email Only**

Customer reminders and communication history are email-only. Email delivery
uses the backend SMTP configuration.

## Development

- Frontend: `npm run dev`
- Frontend production build: `npm run build`
- Backend API: run `npm start` from `backend/`
- Backend tests: run `npm test` from `backend/`

See [backend/SECURITY-OPERATIONS.md](backend/SECURITY-OPERATIONS.md) for
backend configuration, operational safety, and reminder delivery details.
